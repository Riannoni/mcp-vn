# mcp-vn — самостоятельная визуальная новелла в браузере

**Актуальная версия: 0.7.0 (28 октября 2026).** Персональная визуальная новелла с основным интерфейсом **VN Web** в домашней сети. Сохранения, память мира и канонические иллюстрации живут на домашнем сервере. В браузере можно выбирать локального или подключённого внешнего рассказчика и продолжать игру без ChatGPT MCP.

**VN Web:** `http://192.168.50.27:8190/vn/` в текущей установке. [Команды и руководство](docs/VN-WEB.md).

> Это персональный self-hosted проект, настроенный под домашний сервер и ПК с Radeon RX 9070 XT. GitHub содержит **исходный код и инструкции**, но не веса моделей, сохранения, приватные изображения и учётные данные. Текущие адреса в `compose.yaml` и шаблонах сервисов зависят от конкретной сети — перед развёртыванием на другом оборудовании их необходимо изменить.

## Возможности

- **Живой сюжет:** свободный текст игрока, независимые NPC, собственный HTTP-протокол VN Web, история диалога, отмена хода, память мира и опциональные RPG-проверки.
- **Выбор рассказчика:** сюжет в VN Web с выбором локальной/внешней модели; **Cydonia 24B** для приватных локальных эпизодов с **Qwen3.5 9B** как визуальным режиссёром и резервным рассказчиком.
- **Объяснимый выбор изображения:** обычный разговор переиспользует кадр или обновляет только изменённые спрайты; существенная смена позы, одежды, локации или взаимодействия запрашивает один полный **CG**. Без обязательного рендера двух дополнительных спрайтов перед каждым CG.
- **Канонические референсы:** закреплённые лица, варианты одежды и эмоций, кэш фонов и спрайтов, проверка количества основных персонажей и локации.
- **Адаптивный экран:** CG автоматически вписывается целиком (`contain`), переключатель «Вписать / Заполнить», локальные CG 896×1152; широкие фоны сохраняют прежний формат.
- **Локальные GPU-сервисы:** ComfyUI (ROCm/HIP), прозрачные PNG, отдельная CPU-проверка изображений, Wan 2.2 для видео по запросу. Сохранения основной игры не изменяются предварительными локальными CG.

- **Команды VN Web:** `/continue`, `/improvise`, `/ooc`, `/skip`, `/cut`, `/recap`, `/end`, `/video`, `/roll`, `/retry`, `/undo`; подсказки по `/`, серверные кубики, повтор ответа и откат с восстановлением состояния.

## Архитектура

\`\`\`text
Браузер → VN Web на ПК (8190) → домашний сервер (3100)
               │                      │
               ▼                      ▼
       CLIProxyAPI / LLM         состояние, задания,
       Grok / GPT / Cydonia      изображения, память
               │                      ▲
               └→ ComfyUI / GPU worker┘
                   └→ CPU Vision QA
\`\`\`

VN Web использует собственный защищённый HTTP API и локальную графическую очередь. Публичный ChatGPT MCP endpoint удалён; он больше не участвует в работе игры. Внешние рассказчики подключаются через CLIProxyAPI и OAuth провайдера. Встроенные видеомодели и локальные сервисы не требуют MCP.

Lustify, старые Illustrious, DreamShaperXL, RealVisXL, Juggernaut и FLUX.2 Klein удалены из рабочего набора.

Сами веса и права на модели определяются их авторами; перед распространением или коммерческим использованием проверьте лицензии. Подробнее: [модели и лицензии](docs/MODELS.md).

## Быстрый старт

Для текущей установки необходимы домашний Ubuntu-сервер с Docker Compose и игровой ПК с ComfyUI. Настройку ПК, моделей, сервисов и OAuth см. в [руководстве по развёртыванию](docs/INSTALLATION.md).

```bash
git clone https://github.com/Riannoni/mcp-vn.git /opt/mcp-vn
cd /opt/mcp-vn
cp .env.example .env
# Заполните .env собственным токеном игрового воркера и ключами ассетов.
# Проверьте сетевые адреса и порты в compose.yaml.
docker compose config
docker compose build game
docker compose up -d --no-deps game
docker compose ps
curl -fsS http://<YOUR_HOME_HOST>:3100/healthz
```

Без работающего GPU-воркера и локального набора весов сайт может открыться, но генерация медиа не будет доступна. **Не** копируйте настоящие `.env`, ключи SSH, токены OAuth или содержимое каталога `data/` в GitHub.

На ПК запускаются пользовательские сервисы `mcp-vn-comfy.service`, `mcp-vn-worker.service`, `mcp-vn-vision.service` и `mcp-vn-kobold-gateway.service`. Для игры используйте VN Web по адресу ПК; никакие MCP-подключения или отдельные инструменты ChatGPT не требуются.

## Как работает локальное визуальное решение

```text
Действие игрока → рассказчик → сохранение текста
                      ↓
                Qwen visual director
                      ↓
             детерминированный render-policy
                /        |         \
           none/cache  sprite     event CG
             0 GPU    changed    whole frame
                      only        + existing refs
```

Выбранный режим, причина и результат кэша отображаются в игровом UI и возвращаются через `local_episode_status.visual_decision`. Ручная кнопка нового CG пропускает автоматическое переиспользование. Изображения проверяются техническим QA, **но точность сложного физического контакта и всех поз автоматически не гарантируется**.

Для текущей реализации и ограничений см. [Render Policy v6.4](docs/RENDER-POLICY-v64.md) и [архитектуру](docs/ARCHITECTURE.md).

## Проверка и сопровождение

```bash
cd /opt/mcp-vn
docker compose build game     # сборка Vite + Node тесты
docker compose ps
docker compose logs --tail=100 game
# На ПК:
systemctl --user status mcp-vn-worker.service
journalctl --user -u mcp-vn-comfy.service -n 80 --no-pager
```

На последней проверенной сборке прошли **98 Node-тестов**, 5 тестов scene-grounding, 3 visual-contract и 2 теста RAM-кэша референсов. Отдельный тестовый портретный CG Pony в разрешении 896×1152 занимал около 13 секунд. Это пример одного рендера, а не гарантия скорости любого изображения.

### Ограничения

Проект разрабатывается для одного self-hosted развертывания и не является универсальным облачным продуктом. Лицензии checkpoint и модели отдельно от лицензии этого исходного кода. Эффект RAM-кэша зависит от повторного использования референсов; дополнительные 32 ГБ RAM сами по себе не ускоряют GPU diffusion. Качество CG требует проверки человеком: QA преимущественно подтверждает число персонажей и категорию локации.
