# mcp-vn — самостоятельная визуальная новелла в браузере

**Актуальная версия: 0.7.x (28 октября 2026).** Персональная визуальная новелла с основным интерфейсом **VN Web** в домашней сети. Сохранения, память мира и канонические иллюстрации живут на домашнем сервере. В браузере можно выбирать локального или подключённого внешнего рассказчика.

**VN Web:** `http://192.168.50.27:8190/vn/` в текущей установке. [Команды и руководство](docs/VN-WEB.md).

> Это персональный self-hosted проект, настроенный под домашний сервер и ПК с Radeon RX 9070 XT. GitHub содержит **исходный код и инструкции**, но не веса моделей, сохранения, приватные изображения и учётные данные.

## Возможности

- **Живой сюжет:** свободный текст игрока, независимые NPC, собственный HTTP-протокол VN Web, история диалога, отмена хода, память мира и опциональные RPG-проверки.
- **Выбор рассказчика:** основной — внешний (Grok через CLIProxyAPI). Grok ведёт историю, поддерживает мир и отдаёт полные английские промпты для генерации (обычные и NSFW). **Cydonia 24B** — только запасной локальный вариант, если внешний недоступен. Qwen удалён.
- **Объяснимый выбор изображения:** обычный разговор переиспользует кадр или обновляет только изменённые спрайты; существенная смена позы, одежды, локации или взаимодействия запрашивает один полный **CG**.
- **Канонические референсы:** закреплённые лица, варианты одежды и эмоций, кэш фонов и спрайтов.
- **Адаптивный экран:** CG автоматически вписывается целиком (`contain`), локальные CG 896×1152.
- **Локальные GPU-сервисы:** ComfyUI (ROCm), прозрачные PNG, CPU-проверка, Wan 2.2 для видео.

- **Команды VN Web:** `/continue`, `/improvise`, `/ooc`, `/skip`, `/cut`, `/recap`, `/end`, `/video`, `/roll`, `/retry`, `/undo`.

## Архитектура

```text
Браузер → VN Web на ПК (8190) → домашний сервер (3100)
               │                      │
               ▼                      ▼
       CLIProxyAPI / LLM         состояние, задания,
       Grok (primary) / Cydonia  изображения, память
               │                      ▲
               └→ ComfyUI / GPU worker┘
                   └→ CPU Vision QA
```

Внешний рассказчик (Grok) — основной. Он ведёт историю, поддерживает мир и отдаёт полные английские `image_prompts` для локальных моделей генерации. Cydonia — только запасной локальный рассказчик и визуальный план для приватных эпизодов.

## Как работает визуальное решение

```text
Действие игрока → рассказчик (Grok или Cydonia) → сохранение текста
                      ↓
                визуальный план / image_prompts
                      ↓
             prompt-enhancer + render-policy
                /        |         \
           none/cache  sprite     event CG
```

Grok отдаёт полные английские промпты. Для локальных эпизодов Cydonia делает текст + визуальный план. `src/prompt-enhancer.mjs` усиливает промпты quality tags и лучшими negatives для обычных и NSFW сцен.

Изображения проверяются техническим QA. Точность сложного физического контакта требует проверки человеком.
