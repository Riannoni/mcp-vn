# Подключение mcp-vn v0.6.4 к ChatGPT

mcp-vn использует **Streamable HTTP MCP** с визуальным MCP Apps интерфейсом. Это не обычное локальное stdio-приложение и не просто архив ZIP с `mcp.json`: для работы в веб-чате требуется зарегистрированное, доступное и авторизованное MCP-подключение.

## Предварительные условия

- Домашний Node сервер mcp-vn доступен по доверенной сети или VPN.
- Публичный VPS gateway обслуживает защищённый HTTPS endpoint, например `https://YOUR_DOMAIN/vn/mcp`.
- Настроен OAuth/JWT (например, через Auth0); выдача токенов предназначена только разрешённым пользователям.
- Проверено, что публичный анонимный запрос не проходит, а авторизованный MCP `initialize` работает.

## Подключение

1. Откройте ChatGPT → настройки приложений/плагинов (названия могут отличаться по платформам и аккаунтам).
2. Добавьте пользовательский удалённый MCP-сервер, если эта функция доступна, либо используйте уже зарегистрированный `mcp-vn` connector.
3. Укажите **полный публичный URL до `/vn/mcp`**, а не адрес локального ComfyUI и не `:3100` домашнего сервера.
4. Завершите OAuth-авторизацию в браузере. Не выбирайте анонимный доступ вместо требуемой авторизации.
5. Создайте беседу с подключённым mcp-vn; если инструменты кэшируются, переподключите или обновите список tools.

**Актуальный UI:** вызовите `open_game_v64` либо `open_game_latest`. Прежние `open_game_v63` и ранние версии сохранены для старых клиентов, но больше не являются рекомендуемым интерфейсом.

## Что должно появиться

Панель с выбором сохранения, основным кадром слева, историей и формой действий справа. В v6.4 доступны:

- вписывание CG целиком (`contain`) и ручное заполнение кадра (`cover`);
- стандартные фоны и канонические спрайты;
- приватный локальный эпизод с Cydonia/Qwen и выбором `none / sprite / CG`;
- объяснимый текст причины генерации и признак cache-hit;
- ручной CG/video только по прямому действию пользователя.

Основной ход: `submit_action_fast` сохраняет действие, ChatGPT получает `narration_packet` и вызывает `gm_continue_fast` **ровно один раз**. Не надо повторно отправлять уже записанное действие.

## Диагностика

| Проверка | Ожидаемое |
| --- | --- |
| `GET /vn/healthz` на VPS | 200, если gateway настроен на такой маршрут |
| Анонимный запрос к `/vn/mcp` | Отказ 401/403 — нормально |
| OAuth discovery | Работают metadata endpoints, соответствующие вашей конфигурации |
| MCP `initialize` / `tools/list` с авторизацией | Имя `mcp-vn`, присутствует `open_game_v64` |
| Home `/healthz` | версия `0.6.4` |
| `local_model_health` | Cydonia готова, Qwen доступна как director; это проверяет доступность, не запускает генерацию |

**Не полагайтесь на фиксированное число инструментов.** По мере развития проекта их количество меняется.

Если ChatGPT показывает v6.3 после обновления сервера, проблема может быть кэшем UI resource/tool list в клиенте. Используйте новый вызов `open_game_v64` или пересоздайте подключение **без** ослабления OAuth. Если в аккаунте отсутствует функция создания custom MCP, это ограничение возможностей клиента, а не повод публиковать внутренний порт без авторизации.

## Конфиденциальность

Обычная история отправляет контекст главному рассказчику ChatGPT через MCP. Отдельный локальный эпизод обрабатывается локальной Cydonia и Qwen на пользовательском ПК; его подробные реплики не добавляются в обычный контекст ChatGPT. Канонические сохранения не заменяются приватными preview CG.

Никогда не вставляйте `VN_MCP_TOKEN`, `VN_WORKER_TOKEN`, private keys или данные из `data/local-scenes/` в публичные конфиги и чаты поддержки. Дополнительные меры: [SECURITY.md](SECURITY.md).

## Ранее встречавшиеся проблемы

Старый ZIP-плагин мог открываться только в десктопном приложении и не делать облачный MCP доступным. В такой ситуации нужно проверить тип установленного подключения, а не бесконечно переустанавливать ZIP. Для актуального развёртывания предпочтительно зарегистрированное серверное MCP-приложение с OAuth.

Версия и время отклика основного game backend: [OPERATIONS.md](OPERATIONS.md). Схема нескольких серверов: [ARCHITECTURE.md](ARCHITECTURE.md).
