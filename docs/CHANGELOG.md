# История изменений mcp-vn

В этом файле описаны **фактически реализованные** версии. За подробной историей v3–v6.3 см. [архивный README](history/README-v3-to-v64.md). Все численные замеры ниже — конкретные испытания, а не обещание универсальной скорости или качества.

## 0.7.0 — 2026-10-28

- В репозиторий добавлены ранее работавшие отдельно VN Web и Model Lab: `standalone-web/`, сервис запуска и [руководство](VN-WEB.md).
- Отдельный браузерный клиент, общие сохранения, переключение локальных/внешних рассказчиков, device-code OAuth, выбор глубины размышления.
- Исправления картинок: авторизованная раздача с того же origin, асинхронные фон/персонажи, восстановление известных персонажей сцены, управление слоями и CG.
- 11 команд с меню и клавиатурой; серверные кубики, OOC/пересказ вне канона, замена ответа и откат состояния, видео по подтверждению из готового CG.
- Удалены кнопка «Память», отдельная кнопка отката и постоянные технические сообщения. История и задержки отображаются обычным текстом.
- Обновлены README, установка, архитектура и эксплуатация. Сохранения, приватные изображения и ключи исключены из Git.

## 0.6.4 — 2026-10-28

**Выбор изображений и кэши:**
- Детерминированный `src/render-policy.mjs` после локального визуального планирования: `none / sprite / cg` и объяснимые причины выбора.
- Эмоции/небольшие жесты обновляют лишь требуемый прозрачный спрайт, не создавая цельный CG; перемещения влево/вправо управляются DOM.
- Значимые изменения поз, одежды, контакта, сцены и явно заданного ракурса запускают новый CG.
- Убрана обязательная генерация дополнительных полнофигурных спрайтов перед каждым CG. Закреплённые канонические лица продолжают использоваться в поддерживаемых моделях.
- Кэши принятых превью-спрайтов и подтверждённых CG по сигнатуре state; повторный ручной CG намеренно обходит кэш.
- Worker RAM LRU для bytes immutable reference PNG, до 128 МиБ по умолчанию.
- Локальный CG 896×1152; масштабирование в UI `contain` с переключателем `cover`. Старые локальные эпизоды сохраняют предыдущие CG.

**Локальный текст:**
- Cydonia 24B — основная LLM *приватного* эпизода; Qwen3.5 9B — JSON visual director и резервная модель.
- Канонический ChatGPT-GM не заменялся, сохранения не переписывались.
- Шлюз KoboldCpp ROCm/CPU fallback продолжает работать с общим GPU ComfyUI.

**Проверка:** 98/98 Node, 5 scene-grounding, 3 visual-contract, 2 RAM-cache; отдельный нейтральный CG 896×1152 на Pony ~13 сек. Проект поставлен на домашний сервер; подробный журнал внедрения: [RENDER-POLICY-v64.md](RENDER-POLICY-v64.md).

## 0.6.3 — 2026-10-28

- Разделены японское аниме WAI-Illustrious v17 и независимый анимационный стиль Anima BAS:NSFW v1.0.
- CyberRealistic Pony v18 закреплена для реализма, полуреализма и кинопостера.
- Удалена Lustify после переназначения ссылок рабочего воркера; пользовательские изображения и сохранения сохранены.
- Прежний CG локальных эпизодов оставался на Pony. В v6.4 добавлен выбор отдельного режима без дублирования спрайтов.
- Модели проверены нейтральными GPU-рендерами.

## 0.6.2 — 2026-10-28

- Более последовательные CG, предварительный контроль гардероба/поз и проверка совместимости previous-frame.
- Эксперименты с локальными checkpoint через отдельный Model Lab. Не все из них сохранены в рабочем наборе.
- Исторический снимок тестов моделей: [local-image-model-comparison-v62.md](local-image-model-comparison-v62.md).

## 0.6.1 — 2026-10-28

- Усилена независимая проверка количества главных персонажей и типа локации на CG.
- Для новых кадров запрещён невалидный img2img-seed; новые кадры не перенимают устаревшие позы/одежду.
- Технические детали: [scene-grounding-v61.md](scene-grounding-v61.md).

## 0.6.0 — 2026-10-27

- Свободный structured visual state вместо жёстких пресетов одежды/камеры.
- Полноценный neural CG вместо простого CPU-коллажа, ручной запуск Wan 2.2 видео из проверенного кадра.
- Локальный рассказчик сохраняет текст раньше, чем заканчивается отдельный pass визуального планирования.

## v5.7–v5.9 — 2026-10-27

- Отдельный локальный эпизод без попадания его подробного текста в основную переписку.
- Независимый журнал, GPU-координация, асинхронный text inference, развитие логики визуального планирования.
- Исторический документ [local-romance-lane-v57.md](local-romance-lane-v57.md) описывает устаревший Vulkan и двухспрайтовый CG. Для текущего поведения используйте v6.4.

## v5.0–v5.6 — 2026-10-26/27

- Закреплённые лица персонажей и варианты одежды, локальный CLIP/VLM QA, кэш фонов, прозрачные слои и CPU/GPU pipeline.
- Фиксированный стиль внутри сохранения; сюжетная память мира и дополнительные RPG-проверки.
- События UI, компактный narrator packet, замеры задержек и отчёты о стадиях обработки хода.

## v3–v4 — ранние версии

- Первые визуальные интерфейсы MCP, сохранения и генерация ассетов на домашнем ПК.
- Исторический README сохранён только для расследования регрессий, а не как инструкция по развёртыванию.
