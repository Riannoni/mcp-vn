# VN Web: команды и понятный интерфейс

Пользователь задал набор команд по скриншотам Kagesekai и попросил продолжить уже работающий VN Web. Сохраняем существующий интерфейс и стек; отдельная переработка дизайна не нужна.

- Меню у поля ввода: `/continue`, `/improvise`, `/ooc`, `/skip`, `/cut`, `/recap`, `/end`, `/video`, `/roll`, `/retry`, `/undo`. Набор `/` открывает подсказки; выбор вставляет команду. Enter выбирает подсказку, Ctrl/Cmd+Enter отправляет.
- `/ooc` и `/recap` показывают текст отдельно от истории и не меняют канон. `/improvise` разрешает написать ход героя только для этой команды. `/roll` использует серверный генератор случайных чисел; результат сохраняется и передаётся рассказчику.
- `/retry` заменяет последний ответ, сохраняя исходное действие и результат кубиков, восстанавливает предыдущее состояние сцены/памяти. `/undo` отменяет завершённый ход с подтверждением. Смена версии или незаконченный ход блокируют мутации.
- `/video` требует подтверждения и актуального принятого CG; видео — отдельное превью, без изменения сюжета.
- Удаляем кнопки «Память» и отдельный откат. Игровая память сохраняется. Задержки и история — читаемый русский текст. Убираем постоянные сообщения об архитектуре, LAN/VPS и техническую отладку из игрового экрана.
- Существующие незакоммиченные исправления изображений включаем в документацию и сохраняем. Сохранения, ключи и резервные копии не публикуем.

Подход: добавить обработку команд к существующему API и хранилищу. Одна лишь подстановка промптов не подходит для кубиков/отката/изоляции OOC; отдельное приложение дублировало бы уже работающий интерфейс.

Проверка: тесты операций с временными сохранениями, подменой только внешней модели; полный существующий набор тестов в Linux; проверка работающего UI и документации.
