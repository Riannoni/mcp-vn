# mcp-vn v5.7 — локальные эпизоды

## Архитектура

Основной GM — ChatGPT Instant через submit_action_fast и gm_continue_fast. Локальные романтические сцены — Qwen3.5 9B Q4_K_M (GGUF) с KoboldCpp 1.123.1 через Vulkan на Radeon RX 9070 XT. Локальный процесс запускается на запрос и выгружается после ответа.

Авторизованный LAN endpoint локального gateway: 192.168.50.27:11434. Bearer — из уже существующего VN_WORKER_TOKEN. Firewall разрешает порт только для домашнего сервера 192.168.50.29; не публиковать порт через VPS или интернет. Домашний сервер обращается к локальному gateway самостоятельно. Токен не передаётся в браузер.

Каноническая игра сохраняется в data/games. Отдельный журнал частного эпизода хранится в data/local-scenes, с разрешениями 0600, не передаётся в ChatGPT get_game_context и не входит в память основного рассказчика.

## Как играть

В новом клиенте open_game_v57 при завершённом ходе GM нажать кнопку «♡ Локальная сцена». Откроется независимый локальный рассказчик с общим каноном мира и самостоятельным текстом. Это не отправляет действия через ChatGPT. Тексты — на русском языке, взрослые персонажи, романтика и эмоциональная близость без графических сексуальных действий.

Кнопка «♡ CG-кадр» запускает отдельный **неэксплицитный** превью-рендер сцены в semireal из уже принятых прозрачных спрайтов. Превью не меняет канонический CG/костюмы/фон/память.

По кнопке «↩ Вернуться в сюжет» локальный эпизод закрывается, в основной истории сохраняется только нейтральная сводка. Чужие подробные реплики не протекают в контекст ChatGPT. Квесты и отношения не переписываются непроверенными выводами локальной модели.

Вход разрешён только при явно зафиксированном совершеннолетии всех видимых персонажей, участвующих в эпизоде. Если возраст неизвестен или меньше 18, отдельный режим не включается.

## Работа ресурсов

src/gpu-coordinator.mjs запрещает выдачу новых GPU-задач ComfyUI на время локального инференса и ждёт завершения активных GPU-генераций. Затем ComfyUI освобождает кэш моделей и запускается KoboldCpp. По завершении LLM-процесс завершается, освобождая VRAM. ComfyUI и остальные пользовательские systemd-сервисы не перезапускаются.

Отдельные реплики пишутся асинхронно с восстановлением незаконченных ходов после перезапуска сервера. При ошибке основной канон игры не меняется, а клиент показывает ошибку.

## Проверено

56 тестов (включая тест изоляции локального текста, возрастного допуска, GPU-блокировки, асинхронной обработки, safe return и CG preview). Реальная локальная генерация на ПК: 320 токенов за 8.6 с, включая 3.5 с загрузки модели. Первый минимальный пробный ответ: 4.7 с. Тестовый VN-эпизод полностью прошёл по MCP без утечки реплик в основной журнал.

SHA256 загруженного GGUF по Hugging Face LFS: 03b74727a860a56338e042c4420bb3f04b2fec5734175f4cb9fa853daf52b7e8.

## Обслуживание

ПК: systemctl --user status mcp-vn-kobold-gateway.service; журнал — journalctl --user -u mcp-vn-kobold-gateway.service. Приложение и модель — ~/.local/share/mcp-vn-kobold.

Домашний сервер: cd /opt/mcp-vn; docker compose ps; docker compose logs game; curl http://192.168.50.29:3100/healthz.

Бесплатные внешние API пока не подключены: обязательные зависимости не нужны; у облачных бесплатных провайдеров плавающие квоты, задержки, ограничения контента и иная конфиденциальность. Позже можно добавить опциональный fallback только для явно разрешённых неканонических задач, не отправляя приватный сюжет без согласия.

## Обновление v5.8 — качество локального рассказчика и динамических CG

Обнаруженные недостатки v5.7: локальный Qwen иногда говорил за героя,
повторял метафоры о часах и обрывал фразу по достижении лимита 320 токенов.
«CG-кадр» был CPU-копией принятого кадра: запросы на изменения одежды и
позы не влияли на пиксели, а картинки засоряли переписку.

Исправления рассказчика:
- src/local-narrator.mjs строит короткий контекст текущего диалога с ролями
  user/assistant, не повторяет актуальный ввод дважды.
- Факты о головоломке врат включаются только по тематическому запросу,
  а при обычном разговоре не навязываются постоянно.
- В отдельном системном промпте подчёркнуты самостоятельность Миры,
  отсутствие реплик/действий за героя и естественная русская речь.
- Лимит генерации 660 токенов; незаконченное предложение или ответ за
  главного героя отклоняется с одной попыткой исправления.
- Реальная локальная проверка на клоне с романтически-нейтральным диалогом:
  201 токен за 7 секунд, без речи за Макса. Это пример, не гарантия каждого хода.

Новое изображение:
- В локальном эпизоде появились выпадающие списки «Композиция»
  (лицом друг к другу, сидят рядом, объятие, прогулка, крупный план)
  и «Одежда» (канон, повседневная, нарядная).
- При нажатии «✦ Новый CG» сначала независимо генерируются ДВА
  прозрачных GPU-спрайта через ComfyUI с каноническими лицами и новыми
  позами/костюмами; каждый проходит обычную CLIP/VLM/alpha-проверку.
- Только после готовности обоих вариантов отдельный CPU-компоновщик
  собирает новый CG из этих спрайтов на неизменном фоне.
- Готовый кадр — превью, не меняющее scene.cg_url, канонические спрайты,
  цветовую стилистику и память. Провал QA одной фигуры останавливает общий
  CG, а не показывает ошибочное изображение.
- Режим локального чата получил «◧ Скрыть CG / ◈ Показать CG»: превью
  сворачивается и не занимает высоту ленты сообщений.

Двухэтапное генерирование предпочтительнее прямого img2img двух человек,
так как прямой img2img на реальном примере стирал Миру/превращал её
в другого персонажа. В проверенном отдельном CG «Сидят рядом» сохранены
два разных персонажа, поменялась одежда, а Мира действительно села.
Оценка сходства CLIP двух независимых лиц: 0.938 и 0.847.
Базовая сцена реального сохранения осталась прежней.

Важная граница: новый CG создаёт неэксплицитные романтические образы
и не поддерживает сексуальные графические изображения.

## v5.9 — автоматический ИИ-режиссёр (без обязательных ручных поз)

Обновление внедряет второй, отдельный вызов локальной Qwen после каждого принятого
ответа NPC. Рассказчик сначала сохраняет текст, затем дешёвый ИИ-режиссёр
выбирает ракурс, настроение и неэксплицитную одежду по уже подтверждённому
поведению NPC; краткая схема записывается в отдельную сессию.

Когда кадр действительно изменился, движок асинхронно создаёт два
индивидуальных спрайта с сохранением идентичности, ждёт их проверки и
собирает новый preview CG. Основная история, текущие костюмы и канонический CG
не меняются. Сцена появляется в большом визуальном окне слева.

Ручной ракурс перенесён в сворачиваемые дополнительные настройки. Кнопка
«Скрыть CG» управляет только дубликатом изображения в чате и не скрывает
основную локальную сцену слева. При запросе откровенного сексуального CG
интерфейс явно сообщает об ограничении; он больше не выдаёт случайный
одетый рендер за результат такой команды.

Последовательность: локальное действие -> Qwen-текст -> сохранение ->
Qwen JSON режиссуры -> при необходимости отдельные спрайты (ComfyUI GPU) ->
проверка сходства -> CG-композиция (CPU) -> обновление основного локального
экрана. Взаимодействие с ChatGPT остаётся только в обычной ветке GM.

Сквозной тест на отдельном клоне сохранения подтвердил: текст за 6.8 с,
отдельная режиссура за 4.2 с, автоматический план walking, два новых спрайта
с CLIP 0.8604 / 0.8762 и готовый preview CG. Сохранение пользователя
остаётся отдельно и не менялось.

## v6.0 — persistent freeform scene state, full-frame neural CG and opt-in video

The earlier camera and wardrobe presets have been replaced by independent
freeform visual state. Every character carries an outfit, pose, expression,
equipment and action description. The scene tracks location, environment,
camera, light and activity between turns.

The narrator commits prose first; a separate on-device visual-director pass
receives this narration and the last accepted state. A change to the pose,
outfit, equipment or location is enough to request a new still; the model
cannot accidentally lose an important visible change by setting render false.
Older v5.9 sessions are migrated without touching the original main game.

The new local CG workflow takes the GPU queue and renders a whole frame
through SDXL, optionally using the last accepted local CG as an img2img
reference with individually anchored faces. It does not publish into canonical
story art. There are no restrictions to five camera angles or three wardrobes.

Video is a user-triggered Wan2.2 image-to-video workflow starting from the
latest accepted private still. It never starts automatically. The installed
model currently produces 17 frames at 8fps in 512x288 resolution (~2s).

The interface retains a collapsible secondary CG in chat and uses freeform
text instructions for optional camera overrides.
